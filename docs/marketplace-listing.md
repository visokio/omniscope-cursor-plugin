## Full description

One workspace for the whole data journey. From raw data to verifiable insight and decisions you own.

Omniscope connects Cursor to data preparation, analytics and interactive reporting in Omniscope.

Connect and prepare data, build and run visual workflows, analyse results, and create interactive reports—all through conversation. Inspect every step, verify the outputs, and keep a project you can edit and reuse.

Omniscope brings data preparation, analytics and reporting together. Ask Cursor to combine your sources, clean the data, calculate KPIs and build a report. It can create and configure workflow blocks, connect them, run the analysis and inspect the results. Follow the data from source to report, understand how a number was calculated, and keep building on the work.

What will you build?

• Interactive reports from scattered files. Combine Excel or CSV data, standardise fields, join tables and create a report with KPIs and filters.
• A clearer view of your business. Analyse sales, customer renewals, campaign performance or operational data. Compare segments and investigate changes.
• Repeatable data preparation. Clean, blend, reshape, aggregate and validate data using visual ETL workflows you can reuse.
• Advanced analytics. Build workflows using Omniscope’s available forecasting, clustering, statistical and machine learning blocks.
• Explanations for unexpected results. Trace a field to its source, inspect transformations and compare block outputs to investigate missing rows or incorrect calculations.
• Improvements to existing projects. Change a formula, adjust a filter, configure a join or add a calculated field, then run the workflow and inspect the output.

From conversation to a project you control

Start with your own data, an existing project or an available template. Connect files, databases and supported services through Omniscope’s source library. Open the resulting project in Omniscope to explore the interactive report and refine the workflow. Your data, transformations, analytics and insights stay connected in one editable workspace.

Built by Visokio, the creators of Omniscope. Requires an Omniscope Cloud account enabled for AI-agent access. Available connectors and features depend on your account, permissions and configuration. Sign in with your Omniscope account using OAuth. Contact support@visokio.com to request enablement. The plugin does not support purchases.
